# We Eat v1.2.2

## UI copy
- Removed integration diagnostics from the admin overview.
- Replaced implementation-specific references such as backend logs, Cloudinary hosting, database storage, HTTP-only cookies and secure hashes with user-facing language.
- Sanitized frontend service errors so infrastructure details are not displayed to users.

## Dark mode
- Rebuilt the community-feed background for dark mode.
- Added dark variants for badges, kickers, empty states, tables, forms, hero visuals, authentication screens, listing details and content panels.
- Improved button, label, placeholder and muted-text contrast.

## Motion
- Smoother route entrances with blur-to-focus transitions.
- Refined hero stagger timing and card scroll reveals.
- Added restrained hover and press microinteractions.
- Added parallax and smoother floating motion to the homepage preview.
- Preserved reduced-motion accessibility.

No backend or API contract changes.
