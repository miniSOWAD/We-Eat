# We Eat design system

## Primary palette

| Token | Hex | Intended use |
|---|---|---|
| `--cream` | `#FFF2C6` | Free-listing badges, supportive surfaces and secondary calls to action |
| `--cream-soft` | `#FFF8DE` | Section backgrounds and low-emphasis information panels |
| `--blue` | `#AAC4F5` | Discounted-listing badges and secondary highlights |
| `--blue-strong` | `#8CA9FF` | Primary buttons, exchange badges and key interaction emphasis |

The application adds dark neutral text, white cards, semantic success/error colors and accessible focus rings so the supplied four-color palette can function as a complete interface rather than being used indiscriminately.

The original palette image is stored at `docs/palette-reference.png`.
